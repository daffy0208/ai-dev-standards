# Support

If you run into problems or have questions while using the AI Dev Standards
project, please follow these steps:

1. **Search existing discussions** – Review open issues and discussions to see
   if your question has already been answered.
2. **Open an issue** – If you have found a bug or need clarification, open a
   GitHub issue with as much detail as possible (steps to reproduce, logs,
   environment details, etc.).
3. **Security concerns** – For security vulnerabilities, please follow the
   process outlined in `SECURITY.md` rather than filing a public issue.

For general questions, you can also reach the maintainers at
support@ai-dev-standards.example.
