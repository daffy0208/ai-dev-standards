# Skills Storage Directory

## Purpose

This directory stores reusable code artifacts (skills) generated by MCPs using the Code Execution pattern.

## Structure

```
skills/
├── README.md (this file)
├── <skill-name-1>.py
├── <skill-name-2>.py
└── ...
```

## How Skills Work

### Skill Generation

When an MCP using Code Execution pattern solves a task, it can save the solution as a "skill":

- Skills are Python code artifacts
- Named descriptively (e.g., `search_vector_database.py`, `parse_json_schema.py`)
- Stored permanently for reuse

### Skill Reuse

On subsequent runs:

1. Agent checks if a relevant skill exists
2. If found, loads and executes the skill (major token savings)
3. If not found, creates new solution and optionally saves as skill

### Token Savings

- **First run**: 40-60% savings (progressive discovery)
- **With skills**: 85-95% savings (skill reuse)

## Maintenance

### Cleanup

Skills accumulate over time. Periodically review and remove:

- Outdated skills (replaced by better versions)
- Unused skills (no access in 90+ days)
- Deprecated skills (API changes, etc.)

### Backup

Skills represent learned knowledge. Backup regularly:

```bash
tar -czf skills-backup-$(date +%Y%m%d).tar.gz skills/
```

### Monitoring

Track skill usage:

- Most used skills (optimize these)
- Never used skills (candidates for deletion)
- Error-prone skills (need improvement)

## Security Notes

### Skill Validation

- All skills run in sandboxed Docker environment
- Resource limits enforced (memory, CPU, network)
- No access to host filesystem (except mounted skills directory)

### PII Handling

- Skills should NOT contain PII
- PII tokenization happens before skill generation
- Skills operate on tokenized data only

### Code Review

- Periodically audit generated skills
- Look for security issues, inefficiencies
- Refactor commonly-used skills for quality

### Complex Skill: Vector Search

```python
# /skills/vector_similarity_search.py
import numpy as np
from typing import List, Tuple

def cosine_similarity_search(
    query_vector: np.ndarray,
    document_vectors: List[np.ndarray],
    top_k: int = 5
) -> List[Tuple[int, float]]:
    """Find top-k most similar vectors using cosine similarity."""
    similarities = []
    for idx, doc_vec in enumerate(document_vectors):
        similarity = np.dot(query_vector, doc_vec) / (
            np.linalg.norm(query_vector) * np.linalg.norm(doc_vec)
        )
        similarities.append((idx, similarity))

    similarities.sort(key=lambda x: x[1], reverse=True)
    return similarities[:top_k]
```
