## Codex CLI (OpenAI)

**Required By:**

- `codex-review-workflow` skill

**Purpose:**
OpenAI's Codex CLI provides automated code review, analysis, and suggestions through the command line. Used by the codex-review-workflow skill to implement iterative fix-and-review cycles.

### Installation

```bash
npm install -g @openai/codex
```

**Verify Installation:**

```bash
codex --version
# Expected output: codex-cli 0.50.0 (or newer)
```

### Authentication

Codex CLI requires authentication via OpenAI/ChatGPT account:

```bash
codex login
```

This will:

1. Open your default browser
2. Prompt you to log in with your ChatGPT account
3. Authenticate the CLI

**Verify Authentication:**

```bash
codex login status
# Expected output: Logged in using ChatGPT
```

### Testing

Test that Codex CLI is working:

```bash
echo "What is the current date?" | codex exec --sandbox read-only --skip-git-repo-check
```

### Usage Notes

**Sandbox Modes:**

- `--sandbox read-only` - Safest, only reads files
- `--sandbox workspace-write` - Can write to workspace
- `--sandbox danger-full-access` - Full system access (use with caution)

**Git Repository:**

- Codex CLI expects to run in a git repository
- Use `--skip-git-repo-check` if testing outside a git repo
- For actual use, run inside your project's git repository

**Commands:**

- `codex exec` - Execute a code review or analysis task
- `codex login` - Authenticate with ChatGPT account
- `codex login status` - Check authentication status
- `codex --help` - Full command documentation

### Related Skills

- **codex-review-workflow** - Primary skill using Codex CLI for automated code review
- **testing-strategist** - May benefit from Codex's analysis
- **security-engineer** - Can use Codex for security reviews
- **quality-auditor** - Can leverage Codex for quality checks

## Git

**Required By:**

- `codex-review-workflow` skill
- Most development skills (implicit dependency)

**Purpose:**
Version control system used throughout the repository. Required by Codex CLI and most development workflows.

### Installation

**Linux/WSL:**

```bash
sudo apt-get update
sudo apt-get install git
```

**macOS:**

```bash
brew install git
```

**Windows:**
Download from [git-scm.com](https://git-scm.com/download/win)

**Verify Installation:**

```bash
git --version
```

### Configuration

Basic git configuration:

```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

## Troubleshooting

### Codex CLI Issues

**"command not found: codex"**

- Ensure npm global bin is in your PATH
- Try: `npm config get prefix` to see where global packages are installed
- Add to PATH: `export PATH="$(npm config get prefix)/bin:$PATH"`

**"Not logged in"**

- Run: `codex login`
- Ensure browser opens and authentication completes
- Check: `codex login status`

**"This command requires a git repository"**

- Run inside a git repository, or
- Use `--skip-git-repo-check` flag for testing

### Git Issues

**"git: command not found"**

- Install git using instructions above
- Restart terminal after installation
